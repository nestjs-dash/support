# Changelog

## 0.3.0

- Add `ComponentKind` entries for 9 new field kinds: `radio`, `date-picker`, `date-time-picker`, `color-picker`, `code-editor`, `tags-input`, `rich-editor`, `file-upload`, `repeater`.

## 0.2.0

- Add relation action kinds: associate, dissociate, attach, detach (+ bulk variants).
- Add `bulk-action` and `bulk-delete-action` component kinds for table bulk operations.
- Add `dialog` component kind for action modal schemas.
- Add `tabs`, `tab`, and `html` component kinds for Filament-style form layout.
- Add `text-filter` and `date-filter` component kinds.

## 0.1.0

- Initial Nestjs-Dash package release.
